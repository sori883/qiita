# Skill と Subagent を積極活用する

## 使い分け

- **Skill**: 専門知識が必要なタスク → 作業開始前に該当スキルの `SKILL.md` を **`Read` ツールで実読** し、手順/制約をそのまま適用する。宣言だけで終わらせない。
- **Subagent**: 独立コンテキストが有効なタスク（リファクタリング・レビュー・広範囲探索など）、または並列実行したい場合に委任する。

※ 両者は併用可（例: 大規模 codebase の docs-review を Explore に委任して並列実行）。
※ 通常フローで進めて良い目安: 単一ファイル・単一シンボルで完結 / 3 ステップ以内の機械的編集 / 該当 Skill が無い trivial タスク。

## 利用時は明示

使用する Skill/Subagent と理由は1行で明記してから進める。形式例:

> 使用 Skill: `<name>` — <理由 1 行>
> 使用 Subagent: `<name>` — <理由 1 行>

不使用（通常フロー）の場合は宣言不要。
